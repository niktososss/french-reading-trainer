# Lire en français — тренажёр чтения A1

Интерактивный тренажёр правил французского чтения с русскоязычным интерфейсом. 33 темы, 218 слов и словосочетаний, 5 коротких текстов, IPA, озвучка, тесты и повторение ошибок.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `french-reading-trainer` на [GitHub](https://github.com/new).
2. Загрузите файлы `index.html`, `README.md` и `.nojekyll` в корень ветки `main`. Не загружайте архив ZIP вместо файлов. Если `.nojekyll` скрыт, включите показ скрытых файлов или создайте его через Add file → Create new file. Это пустой файл, отключающий обработку Jekyll; для этого проекта он необязателен.
3. Откройте Settings → Pages.
4. В Build and deployment выберите Source: Deploy from a branch, Branch: `main`, Folder: `/(root)`.
5. Нажмите Save. После успешного развёртывания откройте адрес, указанный на странице Pages (обычно `https://USERNAME.github.io/french-reading-trainer/`, где `USERNAME` — имя аккаунта).
6. Для обновления замените `index.html` в той же ветке. GitHub Pages автоматически развернёт обновление.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Запуск без GitHub

Откройте `index.html` в современном браузере. Для тестирования через локальный HTTP-сервер можно выполнить `python3 -m http.server 8000` из корня проекта и открыть `http://localhost:8000/`.

## Технические особенности

- Весь тренажёр находится в `index.html`: HTML, CSS, JavaScript и учебные материалы. Сборка, серверная часть, внешние библиотеки и API-ключи не нужны.
- Прогресс сохраняется локально в браузере (`localStorage`) и не синхронизируется между браузерами, устройствами или разными адресами сайта. При блокировке хранилища результаты остаются только в текущем сеансе.
- Озвучка использует Web Speech API и доступные браузеру французские голоса. Наличие и качество голосов зависят от устройства, браузера и ОС; некоторые голоса могут использовать сетевой сервис производителя. Автоматической проверки произношения с микрофона нет.
- Тренажёр не содержит собственного сбора аналитики, регистрации или передачи учебного прогресса на сервер. Хостинг и системная озвучка могут обрабатывать данные согласно своим условиям.
- Интерфейс поддерживает мобильные экраны и системную светлую/тёмную тему.

Перед публичным размещением убедитесь, что у вас есть право публиковать использованные учебные материалы. Отдельная лицензия на повторное использование не включена.
